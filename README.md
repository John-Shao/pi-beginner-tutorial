# Pi 入门教程

> 从第一次运行 `pi`，到按自己的工作流定制它、给它写扩展，再到把它嵌入其他程序。

Pi 是一个运行在终端里的可扩展智能体运行框架（agent harness）：给它一个目标和一个工作目录，它会读文件、执行命令、修改代码，把多步骤任务做完。它的核心理念是“把 Pi 改成你的工作方式”，而不是让你适应一个固定产品。

本教程按“会用 → 会配 → 会扩展 → 会读源码”的顺序组织，内容同时取材于两处一手资料：

- 官方文档：<https://pi.dev/docs/latest>（与仓库内 `packages/coding-agent/docs/` 同源）
- 源码：Pi 的 monorepo，版本基线为 `@earendil-works/pi-coding-agent` 1.4.0，commit `f09d01b8`

## 适用读者

- 会使用命令行，知道 `cd`、管道、环境变量的含义。
- 能读写 JSON 和 Markdown；第 9、11 章需要能看懂 TypeScript，第 10 章包含 Python 与 TypeScript 示例。
- 对调用大模型 API 有基本概念：API Key、模型名、token、流式输出。

不需要事先读过官方文档。教程按学习路径重排了文档内容，并在关键结论处给出对应文档页和源码位置，方便随时下钻。

## 三条阅读路线

- **快速上手（约 1 小时）**：前言 → 第 1 章 → 第 2 章 → 第 3 章 → 第 5 章。
- **团队落地（约半天）**：快速上手路线 + 第 4、6、7 章，按需查阅附录 A、C。
- **二次开发（约一天）**：第 1、5、8、9 章，然后进入第 10、11 章；第 7 章作为资源定制参考。

## 正文约定

- 命令均可直接复制执行。交互界面里的输入用 `text` 代码块表示，并注明“在 Pi 的编辑器中输入”。
- 配置键、环境变量、函数名、文件路径使用英文原文并加反引号，例如 `settings.json`、`PI_OFFLINE`、`createAgentSession`。
- 每章开头列出“本章你将学会”和对应官方文档；结尾有小结、练习和延伸阅读，练习给出验收标准。
- 结构图、时序图和流程图使用 Mermaid 代码块。GitHub、VS Code 等支持 Mermaid 的阅读器会直接渲染；不支持时仍可按代码块阅读。终端截图存放在 `assets/`。
- “源码位置”的路径相对于 Pi 仓库根目录，例如 `packages/coding-agent/src/core/agent-session.ts`。
- 在线文档统一引用 `https://pi.dev/docs/latest/<slug>`，代码引用文件路径加符号名。
- 教程基线为 Pi 1.4.0。Pi 迭代较快，若新版本行为不同，以官方文档和源码为准，并优先查看包的 `CHANGELOG.md`。
